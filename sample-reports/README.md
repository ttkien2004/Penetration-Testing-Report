# Practice Summaries and Reporting Materials

This folder contains **public-safe summaries** of three privately maintained OSCP-style practice reports. Each original report covers three standalone machines and one Active Directory set. The summaries focus on scope, approach, technical areas practiced, and documentation lessons.

| Summary | Coverage | Focus |
| --- | --- | --- |
| [OSCP-A](oscp-a-practice.md) | 3 standalone systems + 1 AD lab set | Structured enumeration, initial access validation, local and domain context |
| [OSCP-B](oscp-b-practice.md) | 3 standalone systems + 1 AD lab set | Cross-platform assessment, internal service assessment, AD reasoning |
| [OSCP-C](oscp-c-practice.md) | 3 standalone systems + 1 AD lab set | Linux/Windows host assessment, access boundaries, AD analysis |

## Why the original reports are not here

The source documents include platform-specific exercises, target information, and detailed solution material. They are intentionally kept private. These Markdown summaries are **not full reports, walkthroughs, or proof of OSCP certification**.

## Independent sample report

Use [the independent lab assessment template](independent-lab-assessment-template.md) when an independently created or explicitly publishable lab is available. A PDF named `independent-lab-assessment.pdf` is **not included** because no separate publishable assessment was provided. No sample findings have been fabricated.

The template intentionally excludes CVSS scoring and remediation sections for now.
